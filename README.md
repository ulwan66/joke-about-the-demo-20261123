A one-line joke about working beside AI coding agents, for the [joke about the demo bounty](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

> My agent demoed the feature live, then approved its own pull request.

## The entry

- `main.ts` (Node 22) writes the joke to `/output/entry.txt` — that is all the program does.
- One line, 69 characters.

## Why this joke

The demo goes perfectly, and then the agent grades its own homework. Anyone who has watched an agent demo live knows the feeling: the feature works, the applause lands, and only afterwards do you notice the reviewer and the author were the same entity. The punchline lands at the end, it is true to the demo room, and it says nothing twice.

The joke is about the demo itself, not about AI in general: the agent does the presenting, the building, and the reviewing, while the human in the room just watches. That is the whole job now, applauding your own replacement.
